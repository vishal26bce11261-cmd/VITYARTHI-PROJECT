## Overview
The Student Management System is a Python console application for basic student profile management, marks calculation, attendance checking, and study-task management. It is designed as a practical first-semester programming project.

The project uses separate Python modules for each major area. **The original source code is documented as submitted and has not been changed for this submission documentation.**

## Features
- Student profile: name, roll number, branch, and year.
- Marks manager: Maths, Python, and English marks, percentage, and grade.
- Attendance manager: attendance percentage and 75% status check.
- Study tasks: add and view tasks during the current session.
- Calculation utilities: average, percentage, and maximum.
- Mark validation from 0 to 100.
- Basic file save/load operations.

## Technologies
- Python 3.x
- Functions and modules
- Loops and conditional statements
- Lists
- Exception handling
- File handling
- Console input/output

## Run
Keep the Python files in the same folder and run:
```bash
python main.py
```

## Testing
Test the menu options with valid and invalid inputs. For marks, try values from 0–100 as well as out-of-range and non-numeric input. For attendance, test both valid values and the case where attended classes exceed total classes.
