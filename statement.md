# Project Statement

## Project Title
**Student Management System**

**Author:** Vishal Pandey  
**Program:** B.Tech CSE – 1st Semester  
**Institute:** VIT Bhopal University

## Problem Statement
Students regularly handle small academic activities such as maintaining basic profile details, checking marks, calculating attendance, and keeping track of study tasks. Managing these activities separately can be inconvenient. This project brings them together in one simple, menu-driven Python application.

The project is intentionally a beginner-friendly console application. Its purpose is to demonstrate practical use of fundamental Python programming concepts rather than to act as a full institutional student-management platform.

## Scope
The current project covers:
- Student profile information.
- Marks for Maths, Python, and English.
- Total marks, percentage, and grade.
- Attendance percentage and the program's 75% condition.
- Adding and viewing study tasks.
- Basic calculations.
- Marks validation.
- Basic file saving and loading.

The current implementation does not include a database, GUI, web interface, authentication, or networking.

## Target Users
- Students learning Python.
- First-semester programming learners.
- Teachers/evaluators reviewing introductory programming concepts.

## High-Level Features
1. **Student Profile:** collects and saves name, roll number, branch, and year.
2. **Marks Manager:** validates marks, calculates total/percentage, and displays a grade.
3. **Attendance Manager:** calculates attendance and displays status.
4. **Study Tasks:** adds and displays tasks in the current task-manager session.
5. **Utility Modules:** provide calculations, validation, and file operations.

## Expected Outcome
A working, modular, console-based Student Management System demonstrating functions, modules, loops, conditions, lists, exception handling, validation, calculations, and file handling.

## Academic Relevance
The project applies introductory programming concepts to a familiar student-oriented problem and provides a clear example of modular Python development.

## Implementation Note
The source code is kept unchanged. This statement documents the existing project rather than redesigning it.
